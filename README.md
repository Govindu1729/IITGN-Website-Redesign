# IIT Gandhinagar Website Redesign

## 🏛️ Project Overview
A complete redesign of the Indian Institute of Technology Gandhinagar official website, created as a GitHub mini-project submission for METIS - IITGN.

### 🎯 What's Improved
- **Modern Design**: Clean, green-themed UI reflecting IITGN's 5-star GRIHA Green Campus status
- **Better Navigation**: Simplified menu with 5 core sections instead of 20+ items
- **Mobile Responsive**: Fully responsive from 320px to 4K screens
- **Accessibility**: Font controls, grayscale mode, and high-contrast options
- **Performance**: Optimized images and lazy loading for faster load times
- **Clear CTAs**: Prominent "Apply Now" button and improved user flows
